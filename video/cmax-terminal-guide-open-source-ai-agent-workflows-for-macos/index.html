CMAX Terminal Guide: Open-Source AI Agent Workflows for macOS

If you've ever struggled with clunky terminal workflows—juggling multiple panes, zooming in and out, or managing AI agents—CMAX changes everything. This open-source macOS terminal lets you run multiple AI agents in parallel, split panes effortlessly, and zoom independently per terminal. No more resizing headaches or Electron bloat. This guide breaks down how to install, configure, and master CMAX for faster, smoother development.

What This Terminal Lets You Build

By the end of this tutorial, you’ll:

  • Install and set up CMAX, the native Swift terminal for macOS, with GPU-accelerated rendering.
  • Run multiple AI agents (e.g., Cloud Code, Codex, Pi Agent) side-by-side in split panes.
  • Use workspaces and sidebars to organize terminals without switching apps.
  • Zoom in/out per terminal without affecting others—a game-changer for readability.

Requirements Before You Start

  • macOS: CMAX is a native macOS app (not cross-platform).
  • Homebrew (optional): For easy installation (though you can download directly from cmax.com).
  • Terminal basics: Familiarity with CLI commands (e.g., cd, ls).
  • AI agents (optional): Any CLI agent (e.g., Cloud Code, Codex, Pi Agent, Hermes Agent).
  • Ghostty/libghosty: CMAX builds on libghosty, the GPU-accelerated engine behind Ghostty.

Complete CMAX Tutorial: Step-by-Step

1. Install CMAX

Open Terminal and run:

brew install --cask cmax

Or download the .dmg from cmax.com and drag it to Applications. Launch CMAX like any other app—no complex setup required.

2. Navigate the Interface

When you open CMAX, you’ll see a single pane with a cmax welcome message. This shows all keyboard shortcuts. Memorize these:

  • Toggle primary sidebar: Command + B.
  • Toggle secondary sidebar: Command + Option + B.
  • Zoom in/out: Command + Plus/Minus (independent per terminal!).
  • Split panes: Command + D (horizontal) or Command + Shift + D (vertical).

3. Create Workspaces and Split Panes

Workspaces let you group terminals. To create one:

  1. Click the + icon in the left sidebar (or press Command + T).
  2. Split the pane horizontally (Command + D) or vertically (Command + Shift + D).
  3. Run different AI agents in each pane (e.g., cloud code in one, codex in another).

Pro tip: Zoom in on a single pane without affecting others—ideal for debugging or presentations.

4. Run AI Agents in Parallel

CMAX supports any CLI agent. For example:

# In one pane
cloud code start

# In another pane
pi agent run

Agents run independently, so you can monitor logs or outputs side-by-side.

5. Customize and Extend

CMAX is open-source. Fork the repo on GitHub to:

  • Add custom themes or keybindings.
  • Integrate new AI agents via CLI.
  • Contribute to libghosty for GPU rendering improvements.

Troubleshooting: Errors You'll Hit & How to Fix Them

  • Sidebar not appearing: Press Command + B twice to toggle. If it persists, restart CMAX.
  • Zoom not working: Ensure you’re clicking inside the target pane first. Zoom is pane-specific.
  • Agent not recognized: Verify the agent is installed and in your PATH. Run which [agent-name] to check.
  • Slow performance: CMAX is GPU-accelerated. If sluggish, close other GPU-heavy apps (e.g., Chrome tabs).

Where to Take This Further

Once you’re comfortable with CMAX:

  • Explore libghosty to understand how GPU rendering works under the hood.
  • Build a custom AI agent and integrate it into CMAX for your workflow.
  • Contribute to the CMAX GitHub repo—open-source projects thrive on community input.
  • Compare CMAX to Ghostty or iTerm2 to see which fits your needs best.

CMAX isn’t just another terminal—it’s a productivity multiplier for developers and non-technical users alike. Install it, split a few panes, and watch your workflow transform.
