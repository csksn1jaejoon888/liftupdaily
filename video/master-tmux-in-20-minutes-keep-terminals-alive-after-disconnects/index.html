Master Tmux in 20 Minutes: Keep Terminals Alive After Disconnects

If you've ever lost hours of work because your terminal session died when your laptop battery ran out or your SSH connection dropped, this Tmux tutorial is your solution. Learn how to keep terminal sessions running indefinitely, even after disconnects, and manage multiple sessions like a pro.

What This Tmux Tutorial Lets You Build

By the end of this guide, you'll be able to:

  • Run multiple terminal sessions simultaneously without opening new windows or tabs.
  • Keep processes alive even if your laptop dies, your battery runs out, or your SSH connection drops.
  • Detach and reattach sessions seamlessly, allowing you to pick up right where you left off.
  • Use Tmux on a VPS to run long-running tasks like AI agents, refactoring scripts, or server processes for days at a time.

Requirements Before You Start

  • A terminal (macOS Terminal, iTerm2, Linux terminal, or Windows Terminal with WSL).
  • macOS: Homebrew installed (for easy Tmux installation).
  • Linux: Package manager like apt, yum, or dnf.
  • Windows: WSL (Windows Subsystem for Linux) or a Linux VM.
  • Basic familiarity with terminal commands (e.g., cd, ls, ping).

Complete Tmux Tutorial: Step-by-Step

Step 1: Install Tmux

Open your terminal and install Tmux using your system's package manager:

  • macOS: Run brew install tmux.
  • Linux (Debian/Ubuntu): Run sudo apt install tmux.
  • Linux (Fedora/RHEL): Run sudo dnf install tmux.
  • Windows (WSL): Follow the Linux instructions above in your WSL terminal.

Verify the installation by running tmux -V. You should see the installed version (e.g., tmux 3.3a).

Step 2: Start a New Tmux Session

Create a new named session to keep your work organized. Run:

tmux new -s session_name

Replace session_name with a descriptive name, like testing or youtube. You'll see a green status bar at the bottom of your terminal, indicating you're inside a Tmux session.

Step 3: Run Commands Inside Tmux

While inside the Tmux session, run any command as you normally would. For example:

ping google.com

This command will keep running until you stop it. The magic of Tmux is that this process will continue even if you disconnect.

Step 4: Detach from the Session

To detach from the session (leaving it running in the background), press Ctrl+B, then D. You'll see the message [detached] and return to your regular terminal. The ping command (or any other process) will continue running.

Step 5: Reattach to the Session

To reattach to your Tmux session, run:

tmux attach -t session_name

Replace session_name with the name of your session. You'll be right back where you left off, with all processes still running.

Step 6: Use Tmux on a VPS (Advanced)

For long-running tasks, like AI agents or large refactors, run Tmux on a VPS. Here's how:

  1. SSH into your VPS: ssh user@your_vps_ip.
  2. Start a Tmux session on the VPS: tmux new -s vps_session.
  3. Run your long-running task inside the session.
  4. Detach from the session (Ctrl+B, then D).
  5. Disconnect from the VPS (exit). Your task will keep running.
  6. Reconnect later and reattach to the session: tmux attach -t vps_session.

Troubleshooting: Errors You'll Hit & How to Fix Them

  • Error: tmux: command not found: Tmux isn't installed. Follow the installation steps for your OS.
  • Error: no sessions when trying to attach: You may have mistyped the session name. List all active sessions with tmux ls and try again.
  • Error: Can't detach from session: Ensure you're pressing Ctrl+B, releasing both keys, then pressing D. If you're on macOS, use Command+B instead of Ctrl+B if configured.
  • Error: Session killed unexpectedly: If your VPS reboots, Tmux sessions will terminate. Use tmux-resurrect or tmux-continuum plugins to auto-save and restore sessions.

Where to Take This Further

Now that you've mastered the basics, explore these advanced Tmux features to supercharge your workflow:

  • Split panes: Use Ctrl+B + % to split horizontally and Ctrl+B + " to split vertically.
  • Customize your Tmux config: Edit ~/.tmux.conf to change key bindings, colors, and status bar settings.
  • Use Tmux plugins: Install plugins like tmux-resurrect to save and restore sessions automatically.
  • Run Tmux on a cloud server: Set up a VPS (e.g., DigitalOcean, AWS, or Linode) to run Tmux sessions 24/7 for long-running tasks.

Tmux is a game-changer for developers, AI engineers, and anyone who relies on the terminal. Start using it today to keep your sessions alive, manage multiple tasks, and boost your productivity.
